Агенты спят ночью.
И ты тоже.Agents sleep at night.
So do you.

Night Guard — самоограничитель вайбкодинга. С 23:00 до 07:00 Claude Code и Codex не принимают промпты и не выполняют действия. Даже задачи, запущенные вечером, остановятся. Night Guard is a self-imposed limit for vibe coding. From 11 pm to 7 am, Claude Code and Codex refuse prompts and tool calls, so even tasks you started in the evening stop.

Как это работаетHow it works

Официальные хуки,
никакой магииOfficial hooks,
no magic

Night Guard регистрирует один маленький скрипт в официальной системе хуков обоих агентов. Днём он молча пропускает всё. Ночью — отказывает.Night Guard registers one small script with each agent's official hook system. During the day it lets everything through without a word. At night it says no.

1. Ты пишешь промпт1. You send a prompt

Срабатывает UserPromptSubmit. Ночью промпт не уходит в модель.UserPromptSubmit fires. At night, the prompt never reaches the model.

{"decision": "block",
 "reason": "Иди спать…"}
→

2. Агент хочет действовать2. The agent tries to act

Каждый вызов инструмента проходит через PreToolUse — правка файла, команда, поиск.Every tool call goes through PreToolUse: file edits, commands, searches.

"permissionDecision":
  "deny"
→

3. Работа ждёт утра3. Work waits for morning

Агент получает отказ и просьбу остановиться. Утром всё снова работает само.The agent is refused and told to stop. In the morning everything works again on its own.

Защита от сбоевFail-closed

Конфиг испорчен? Включается расписание 23:00–07:00 по умолчанию. Защита не отключается молча.Broken config? It falls back to the default 23:00–07:00 window. Protection never switches itself off without telling you.

Безопасный конфигSafe config

Настройки читаются как данные и никогда не исполняются. Пауза ограничена по длительности.Settings are read as data and never executed. Pause length is capped.

УстановкаInstall

Минута — и готовоDone in a minute

Установщик сам найдёт Claude Code и Codex и подключит хуки.The installer finds Claude Code and Codex and adds the hooks for you.

git clone https://github.com/qlmsv/night-guard.git
cd night-guard && ./install.sh

Приложение собирается из исходников (нужен swiftc: xcode-select --install). Без него: ./install.sh --no-app.The app is built from source and needs swiftc (xcode-select --install). Without it, run ./install.sh --no-app.

git clone https://github.com/qlmsv/night-guard.git
cd night-guard
powershell -ExecutionPolicy Bypass -File install.ps1

Без git: скачайте ZIP на GitHub (Code → Download ZIP), распакуйте и выполните последнюю команду в этой папке. Значок появится в трее и в автозагрузке.No git? Download the ZIP from GitHub (Code → Download ZIP), unpack it, and run the last command in that folder. The icon appears in the tray and is added to startup.

git clone https://github.com/qlmsv/night-guard.git
cd night-guard && ./install.sh --no-app

Нужны bash и jq. Управление — команда nightguard.Requires bash and jq. Manage it with the nightguard command.

⚠️ Codex запускает хуки только после одобрения: один раз откройте Codex, выполните /hooks и доверьте хукам Night Guard.Codex only runs hooks you have approved: open Codex once, run /hooks, and trust the Night Guard hooks.
FAQ

ВопросыQuestions

А если мне правда нужно поработать ночью?What if I really need to work at night?

Возьми экстренную паузу (до 30 минут, один раз за ночь) — в приложении или командой nightguard pause 20. Или подкрути расписание днём.Take an emergency pause (up to 30 minutes, once a night) in the app or with nightguard pause 20. Or adjust the schedule during the day.

Это работает в облаке и в веб-чате?Does it work in the cloud or in web chat?

Нет. Только локальные Claude Code (терминал, приложение, IDE) и Codex (CLI, приложение). Облачные сессии и claude.ai / chatgpt.com не затрагиваются.No. Only local Claude Code (terminal, desktop app, IDE) and local Codex (CLI, app). Cloud sessions and claude.ai / chatgpt.com aren't affected.

Не сломает ли он мои настройки?Will it break my settings?

Установщик меняет только свои записи, сохраняет остальное и делает копию *.night-guard.bak. Удаление убирает только хуки Night Guard.The installer only touches its own entries, keeps everything else, and saves a *.night-guard.bak copy. Uninstalling removes only the Night Guard hooks.

Можно ли его обойти?Can it be bypassed?

Да, если специально редактировать файлы. Это не DRM, а договор с самим собой: достаточно трения, чтобы сонный ты передумал.Yes, if you deliberately edit the files. It's not DRM, it's a deal with yourself: enough friction that sleepy you changes your mind.
